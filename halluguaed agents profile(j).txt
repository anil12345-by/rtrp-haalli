# **7. Install the Email Extension Plugin**

Now comes the email notification part.

We want Jenkins to send an email whenever:

- The build succeeds.
- The build fails.

For this, we'll use the **Email Extension Plugin**, also called `email-ext`. It provides the `emailext` Pipeline step.&#x20;

[image](https://www.google.com/s2/favicons?domain=https://plugins.jenkins.io\&sz=32)

Jenkins plugin+1



### **Step 1: Install the plugin**

Go to:

```
Dashboard
→ Manage Jenkins
→ Plugins
→ Available plugins
```

Search:

```
Email Extension
```

Select it and click Install.

Also check whether the Mailer plugin is installed.

Restart Jenkins if the plugin installation requests it.

### **Step 2: Configure SMTP**

For this example, we'll use Gmail.

Open:

```
Manage Jenkins → System
```

Find the section:

**Extended E-mail Notification**

Configure the following:

| Setting                 | Value                   |
| ----------------------- | ----------------------- |
| SMTP Server             | `smtp.gmail.com`        |
| SMTP Port               | `587`                   |
| Use SMTP Authentication | Enabled                 |
| Username                | Your Gmail address      |
| Password                | Your Gmail App Password |
| Use TLS                 | Enabled                 |
| Use SSL                 | Disabled                |

For Gmail, port 587 uses STARTTLS. Port 465 uses implicit SSL/TLS. We'll use port 587.&#x20;

# **8. Create the complete Jenkins Pipeline with Email Notification**

Now we'll combine everything into one practical.

This is the main part to remember for your external.

### **Step 1: Create Jenkinsfile**

Open your Maven Web Project in Eclipse.

At the same level as `pom.xml`, create a new file named:

```
Jenkinsfile
```

Your project should look like:

```
LibraryWebApp
│
├── src
│   └── main
│       └── webapp
│           └── index.jsp
│
├── pom.xml
└── Jenkinsfile
```

### **Step 2: Add this complete Jenkinsfile**

Replace `YOUR_USERNAME` and the email addresses with your own details.

```

pipeline {

    agent any

    tools {
        jdk 'JDK21'
        maven 'Maven3'
    }

    stages {

        stage('Checkout') {
            steps {
                echo 'Fetching project from GitHub'
                checkout scm
            }
        }

        stage('Build') {
            steps {
                echo 'Compiling Maven project'
                bat 'mvn -B clean compile'
            }
        }

        stage('Test') {
            steps {
                echo 'Running test cases'
                bat 'mvn -B test'
            }
        }

        stage('Package') {
            steps {
                echo 'Creating WAR file'
                bat 'mvn -B package'
            }
        }
    }

    post {

        success {
            emailext(
                to: 'YOUR_EMAIL@gmail.com',
                subject: "SUCCESS: ${env.JOB_NAME} - Build #${env.BUILD_NUMBER}",
                body: """
Hello,

Your Jenkins build completed successfully!

Project: ${env.JOB_NAME}
Build Number: ${env.BUILD_NUMBER}
Status: SUCCESS

Build URL: ${env.BUILD_URL}

The Maven project was successfully built and packaged.

Regards,
Jenkins
"""
            )
        }

        failure {
            emailext(
                to: 'YOUR_EMAIL@gmail.com',
                subject: "FAILURE: ${env.JOB_NAME} - Build #${env.BUILD_NUMBER}",
                body: """
Hello,

Your Jenkins build has FAILED.

Project: ${env.JOB_NAME}
Build Number: ${env.BUILD_NUMBER}
Status: FAILURE

Please check the console output:
${env.BUILD_URL}console

Regards,
Jenkins
"""
            )
        }

        always {
            echo 'Jenkins pipeline execution completed.'
        }
    }
}

```

### **Understand the Jenkinsfile**

| Section     | Purpose                             |
| ----------- | ----------------------------------- |
| `pipeline`  | Defines the pipeline                |
| `agent any` | Runs on an available agent          |
| `tools`     | Specifies configured JDK and Maven  |
| `stages`    | Contains build stages               |
| `Checkout`  | Gets source code                    |
| `Build`     | Compiles Java code                  |
| `Test`      | Runs test cases                     |
| `Package`   | Generates WAR                       |
| `post`      | Executes actions after the pipeline |
| `success`   | Sends success email                 |
| `failure`   | Sends failure email                 |
| `emailext`  | Sends customized email              |

The `post` conditions are provided by Declarative Pipeline, and `emailext` is supplied by the Email Extension plugin.&#x20;

[image](https://www.google.com/s2/favicons?domain=https://www.jenkins.io\&sz=32)

Jenkins+2



**Important:** The names `JDK21` and `Maven3` must exactly match the names you configured under Manage Jenkins → Tools.

Also, `checkout scm` assumes you've configured the Pipeline job to retrieve its Jenkinsfile from GitHub.

# **12. Configure automatic build triggering**

So far, we've manually clicked Build Now.

Let's automate it.

For local laptop practice, we'll use Poll SCM.

Open your Pipeline job:

```
Configure → Build Triggers
```

Select:

**Poll SCM**

Enter:

```
H/5 * * * *
```

Save.

This makes Jenkins periodically check the GitHub repository for changes, approximately every five minutes.

Alternatively, in your Jenkinsfile you can add:

```
triggers {
    pollSCM('H/5 * * * *')
}
```

Put it inside the `pipeline` block, outside `stages`.

Now the workflow becomes:

1. Modify your Java or JSP file.
2. Commit the change.
3. Push it to GitHub.
4. Jenkins detects the new commit.
5. Jenkins automatically runs the pipeline.
6. Jenkins sends an email containing the build result.

# **14. Common Jenkins errors and solutions**

| Error                         | Reason                            | Solution                        |
| ----------------------------- | --------------------------------- | ------------------------------- |
| `mvn is not recognized`       | Maven unavailable to Jenkins      | Configure Maven under Tools     |
| `JAVA_HOME is not defined`    | JDK not configured                | Set JDK installation            |
| `Git not found`               | Incorrect Git path                | Configure Git executable        |
| `Authentication failed`       | GitHub credentials issue          | Configure Personal Access Token |
| `No such DSL method emailext` | Email Extension plugin missing    | Install email-ext               |
| `Failed to send email`        | SMTP configuration issue          | Check App Password and TLS      |
| `Connection refused`          | Wrong port or service not running | Check Jenkins and SMTP ports    |
| `BUILD FAILURE`               | Compilation or test error         | Check Console Output            |

# **15. Email notification in Freestyle jobs**

If your examiner asks for email notification in a Freestyle project instead of Pipeline, follow these steps.

1. Open your Freestyle job.
2. Click Configure.
3. Scroll to Post-build Actions.
4. Click Add post-build action.
5. Select Editable Email Notification.
6. Enter your recipient email.
7. Configure the triggers.

Recommended settings:

| Trigger       | Purpose                                    |
| ------------- | ------------------------------------------ |
| Success       | Email when build succeeds                  |
| Failure - Any | Email when build fails                     |
| Unstable      | Email when tests fail or build is unstable |

Click Save and execute the job.

The same SMTP configuration from Section 7 is used.
