Question 3. Containerization and Deployment using Minikube (25 Marks)
Task:
Deploy the Maven web application Docker image available in the student's own Docker Hub repository using Minikube and Kubernetes.
•	Start a Minikube cluster and verify that it is running successfully.
•	Create a Kubernetes Deployment to deploy the application image from Docker Hub.
•	Create a Kubernetes Service to expose the application using NodePort. Configure the targetPort to match the application's container port and use a valid NodePort.
•	Verify the Deployment and Service using appropriate kubectl commands.
•	Scale the Deployment to four replicas.

•	Verify the Service configuration, NodePort mapping and application accessibility through the Minikube service URL.
